# Выпуск «Ash & Crown» в Steam, Google Play и App Store

Что уже сделано в проекте, а что нужно сделать в магазинах.

## Уже настроено в проекте

Выставляется автоматически при открытии проекта (`Assets/Editor/ProjectSetup.cs`):

| | |
|---|---|
| Название | **Ash & Crown** (внутри игры — по выбранному языку) |
| Компания | VoidRunar |
| Идентификатор (Android и iOS) | `com.voidrunar.ashandcrown` — после первой публикации не меняется |
| Версия | 0.9.0, номер сборки 1 (Android `bundleVersionCode`, iOS `buildNumber`) |
| Иконки | общая `icon.png`; iOS — без прозрачности (`icon_opaque.png`); Android — адаптивная (`android_bg.png` + `android_fg.png`) |
| Экран | только горизонтально, на iPad — во весь экран |
| Android | IL2CPP, ARM64, сборка `.aab`, разрешение на интернет |
| iOS | в Info.plist — доступ к локальной сети и отметка «шифрование не используется» |
| Политика конфиденциальности | `docs/privacy.html` (русский и английский) |

Номер версии виден в главном меню слева внизу.

**Новая версия:** в `Edit → Project Settings → Player` подними Version (например, 0.9.1) и **обязательно**
увеличь Bundle Version Code (Android) и Build (iOS) — магазины не примут сборку с тем же номером.

## Политика конфиденциальности (нужна Google Play и App Store)

1. Репозиторий на GitHub должен быть публичным (бесплатные GitHub Pages работают только для публичных).
2. GitHub → репозиторий → **Settings → Pages** → Source: *Deploy from a branch*, Branch: `main`, папка `/docs` → Save.
3. Через минуту страница откроется по адресу `https://novusegoist.github.io/Chess2.0/privacy.html`.
   Эту ссылку указываешь в Google Play Console и App Store Connect.

## Steam

1. Steamworks: зарегистрироваться как разработчик (Steam Direct, взнос $100 за игру) и получить свой **AppID**.
2. Записать AppID в `steam_appid.txt` вместо 480 (и класть файл рядом с `.exe` при тестах).
3. Steamworks → настроить депо, загрузить сборку Windows (`File → Build Profiles → Windows → Build`) через SteamPipe.
4. Страница магазина: описание (русское и английское), скриншоты, капсулы (обложки), трейлер.
5. Steam просит заполнить анкету о контенте и указать, собирает ли игра данные: данные не собираются.
6. Позже: достижения Steam (они уже есть в игре — нужно связать их с API Steam).

## Google Play

1. Аккаунт разработчика Google Play Console (разовый взнос $25).
2. **Ключ подписи:** `Player Settings → Publishing Settings → Keystore Manager` → создать keystore.
   Сохрани файл и пароли в надёжном месте — без них нельзя выпустить обновление.
   В консоли включи *Play App Signing* (Google хранит итоговый ключ, твой становится ключом загрузки).
3. Переключиться на Android (`Build Profiles → Android → Switch Platform`), **перезапустить Unity**, собрать `.aab`.
4. Play Console → создать приложение → загрузить `.aab` сначала во *внутреннее тестирование*.
5. Заполнить:
   - **Политика конфиденциальности:** ссылка на GitHub Pages;
   - **Безопасность данных (Data safety):** данные не собираются и не передаются; шифрование при передаче — нет
     (игра по IP идёт напрямую между устройствами, своего сервера нет);
   - **Возрастной рейтинг (IARC):** насилия, азартных игр и т.п. нет; есть общение между игроками (чат в сетевой игре);
   - **Целевая аудитория:** 13+ (из-за чата с незнакомыми игроками проще не указывать детей);
   - **Реклама:** нет;
   - описание, скриншоты телефона и планшета (горизонтальные), картинка 1024×500.
6. Новым личным аккаунтам Google требует закрытый тест: 12 тестировщиков в течение 14 дней — только потом публикация.

## App Store

1. Нужен **Mac с Xcode** и аккаунт **Apple Developer Program** ($99 в год).
2. На Windows: `Build Profiles → iOS → Switch Platform` → перезапустить Unity → Build. Получится проект Xcode.
3. Перенести папку на Mac, открыть `Unity-iPhone.xcodeproj`, выбрать свою команду (Signing & Capabilities),
   Product → Archive → Distribute App → App Store Connect.
4. App Store Connect:
   - **Privacy Policy URL:** ссылка на GitHub Pages;
   - **App Privacy:** *Data Not Collected*;
   - **Age Rating:** нет насилия и т.п.; есть общение с другими игроками;
   - скриншоты iPhone 6.7"/6.5" и iPad 12.9" (горизонтальные), описание, ключевые слова;
   - **Export Compliance:** уже отмечено в сборке (своё шифрование не используется).
5. Сначала TestFlight, потом отправка на проверку.

## Перед каждым выпуском

- [ ] Подняты Version и номер сборки (Android и iOS).
- [ ] Тесты ядра проходят: `dotnet run --project Tools/CoreTests -c Release`.
- [ ] Проверены: игра с ботом, вдвоём, по сети, уроки, сохранение, оба языка.
- [ ] На телефоне: экран с вырезом, кнопка «Назад» на Android, сворачивание и возврат в игру.
